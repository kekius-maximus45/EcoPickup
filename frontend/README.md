# EcoPickup Frontend

This folder contains the browser interface for EcoPickup.

- HTML files contain the individual screens.
- `style.css` contains the shared responsive design.
- `script.js` contains frontend interactions and calls the Spring Boot `/api` endpoints.
- `images/` is ready for uploaded or static image assets.

For the complete working application, start Spring Boot from the sibling `backend` folder and open `http://localhost:8080`. Opening these HTML files directly will show the design, but database-backed actions require the backend server.
